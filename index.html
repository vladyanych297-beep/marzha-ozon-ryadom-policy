ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ
Приложение «Маржа Ozon рядом», версия 1.0.6
Редакция от 11 ноября 2026 года
Разработчик: ESI.Company
Контакт для вопросов и обращений: esi.compay@yandex.ru

1. Назначение
Независимое бесплатное приложение рассчитывает показатели по товарам собственного магазина пользователя в Ozon Seller. Приложение не является продуктом Ozon. Регистрация учётной записи у разработчика не требуется.

2. Какие данные обрабатывает приложение
Пользователь вводит Client ID, API-ключ Seller API и себестоимость товаров. По запросу пользователя телефон получает от Ozon каталог (ID, SKU, артикулы, названия), отправления (номера и количества товаров), финансовые начисления, денежную цену продажи, денежные начисления программ партнёров, комиссии, возвраты и общие расходы. Баллы за скидки включаются в расчёт и сохраняются в составе финансовых строк отчёта.
Данные используются для проверки подключения и формирования отчёта. Отправления могут содержать дополнительные поля, предоставляемые самим API Ozon. Приложение не запрашивает включение legal_info, analytics_data и financial_data в списках отправлений, не использует сведения покупателей для расчёта и не сохраняет полные ответы отправлений. Полученный ответ временно находится в памяти телефона для разбора; сохраняются необходимые номера отправлений, схема, статус, дата создания, SKU, количества, строки финансовых начислений и агрегированные показатели для просмотра деталей и отчёта. Сведения о покупателях и полный исходный ответ отправления не сохраняются.

3. Передача данных
Запросы идут непосредственно с телефона на https://api-seller.ozon.ru по HTTPS с Client ID и API-ключом в заголовках. Ozon также получает обычные сетевые сведения, например IP-адрес, время и параметры запроса; его обработка регулируется документами Ozon и договором пользователя с Ozon.
У разработчика нет центрального сервера для данных магазина. Приложение не отправляет разработчику ключи, отчёты или себестоимость. Оно не содержит рекламных, аналитических или crash-reporting SDK и не ведёт сетевую телеметрию. Нет передачи данных другим магазинам.
Демонстрационный режим использует вымышленные данные и не обращается к Ozon.
Установка и обновления через RuStore обрабатываются самим RuStore по его документам; SDK RuStore в приложение не встроен.

4. Хранение и защита
Client ID и API-ключ сохраняются в одном зашифрованном контейнере AES-GCM в закрытом хранилище приложения. Ключ шифрования создаётся и хранится средствами Android Keystore и не экспортируется приложением. Аппаратная защита зависит от устройства; приложение её не гарантирует.
Себестоимость, последний успешный агрегированный отчёт, детализация отправлений и финансовых строк, время ожидания после лимита и промежуточная загрузка хранятся локально в закрытом каталоге приложения Android. Эти файлы не имеют отдельного прикладного шифрования: их защищают изоляция приложений и доступные средства шифрования/блокировки Android. На взломанном устройстве или при доступе к разблокированному телефону абсолютная защита не гарантируется.
Настройка «Не выключать экран» хранится локально и использует флаг окна Android только при открытом приложении, без изменения системного тайм-аута и без нового разрешения.
Автоматическое резервное копирование и перенос данных средствами приложения отключены. Поле API-ключа скрыто, не сохраняется в состоянии экрана; скриншоты и запись экрана разрешены средствами Android, в том числе для отчёта реального магазина. Приложение не записывает ключ или тела ошибок API в журналы.

5. Сроки и удаление
Ключ, себестоимость и последний успешный отчёт хранятся до удаления пользователем или перезаписи. Успешный отчёт заменяет предыдущий; себестоимость хранится до изменения/удаления. Промежуточная загрузка используется до двух часов с начала, затем игнорируется и заменяется при следующей загрузке; после успешного формирования отчёта удаляется. Отключение/очистка удаляет и её.
Вкладка «Магазин» → «Удалить ключ и все локальные данные» удаляет локальные файлы и ключ шифрования. Удаление приложения или очистка данных через Android также удаляет локальные сведения. Восстановления, облачного экспорта и синхронизации между телефонами нет. Обычное обновление приложения с той же подписью сохраняет данные.
Удаление локального ключа не отзывает доступ в Ozon. Для отзыва удалите соответствующий API-ключ в кабинете Ozon Seller. Данные и отчёты на стороне Ozon подчиняются правилам Ozon, приложение их не удаляет.

6. Разрешения
Требуется только доступ к интернету. Приложение не запрашивает контакты, геолокацию, камеру, микрофон, телефон, общее файловое хранилище или право устанавливать APK. Доступ к локальным файлам приложения не требует отдельного разрешения.

7. Обращения
Для вопросов используйте esi.compay@yandex.ru. Если вы сами отправите письмо, почтовый сервис и получатель получат адрес отправителя и содержимое письма. Не прикладывайте ключи, пароли, персональные сведения покупателей или конфиденциальные отчёты. Разработчик не может удалённо прочитать или восстановить локальную себестоимость. Запрос на удаление переписки можно направить на тот же адрес; хранение и удаление переписки регулируются также средствами используемой почты и применимыми требованиями закона. О передаче данных по требованию закона судят по применимым нормам.

8. Изменения
При изменении фактической обработки публикуется новая редакция политики с датой. Действующая редакция поставляется в приложении на вкладке «Инструкция». Публичная веб-копия для карточки RuStore должна соответствовать этой редакции.
